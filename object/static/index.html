    BEFORE GENERATING
    生成提示
    较长或内容复杂的材料可能导致生成耗时显著增加，或因解析、模型响应等限制而生成失败。例如：超过 70 页的 PPT、图片较多的 PDF、多份材料组合上传或较长录音。
    生成速度会受到材料质量与长度、图片和公式数量、网络状况、模型响应速度，以及生成要求的详细程度影响。
    通常需要几分钟；复杂材料可能需要 30 分钟或更久。生成会在后台继续进行，你可以在“最近任务”中查看进度。
    对这类材料，建议先在本地按章节或主题拆分后分批处理；如仍需一次性上传，请预留更长生成时间。
    如果生成中断或出现异常，可在“最近任务”中选择“重试未完成步骤”；已完成的解析和知识提取会尽量复用，无需从头处理。
    MODEL ROUTING
    模型与 API 设置
    为新任务选择模型。已运行的任务不会受影响。
    密钥仅发送到本机后端，不会被前端读取、缓存或展示。接口需兼容 OpenAI Chat Completions。
    默认模型填一组即可作为全部非 ASR 步骤的兜底
    按角色覆盖通常只需要配置默认模型
    ASR · 音频转写可选；上传录音前需要配置
